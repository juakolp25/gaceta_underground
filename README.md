📰 Gaceta Underground: Revolución Digital 1810
GACETA UNDERGROUND es una experiencia interactiva de "hacking histórico" basada en la vida y obra de Mariano Moreno. Ambientada en el Buenos Aires de 1810, los usuarios actúan como agentes encubiertos que deben utilizar terminales, descifrar códigos y burlar la censura realista para propagar los ideales de la Revolución de Mayo.

🕹️ El Sistema
La interfaz imita un documento clasificado de nivel Omega, combinando texturas de papel antiguo con una terminal de comandos moderna y efectos de glitch. El repositorio incluye:

10 Misiones Críticas: Desde la infiltración en la Imprenta de los Niños Expósitos hasta la fundación de la Biblioteca Nacional.

Mecánicas Diversas:

Terminal de Comandos: Ejecución de protocolos bash para neutralizar firewalls realistas.

Descifrado de Código: Resolución de algoritmos en JavaScript (como ROT-13 invertido) para recuperar mensajes de Rousseau.

Recuperación de Manifiestos: Identificación de palabras clave censuradas en el Plan de Operaciones.

Arte ASCII: Visualización de nodos tácticos y retratos tipográficos de la era revolucionaria.

🛠️ Tecnologías
Este sistema de infiltración ha sido desarrollado con:

React.js: Para la gestión de estados de misiones y renderizado dinámico.

Framer Motion: Responsable de las animaciones de "estampado", transiciones de pantalla y efectos de glitch visual.

CSS Keyframes: Animaciones personalizadas para el parpadeo de terminal, ruido de papel y líneas de escaneo (scanlines).

Google Fonts: Utiliza Special Elite para la estética de máquina de escribir y Share Tech Mono para la interfaz de hackeo.

📂 Archivo Principal: MarianoMoreno.jsx
El núcleo del sistema reside en este componente, que gestiona:

Missions Data: Una base de datos con narrativa histórica real y desafíos lógicos.

Terminal Simulator: Un motor que procesa comandos simulados y valida secuencias de hackeo.

Thematic Palette: Un esquema de colores basado en ink (#1a1208) y red (#b8001f) para máxima inmersión.

🚀 Despliegue Local
Para iniciar la Gaceta en tu nodo local:

Clonar el repositorio:

Bash
git clone https://github.com/juakolp25/gaceta_underground.git
Instalar protocolos:

Bash
npm install
Ejecutar infiltración:

Bash
npm start
